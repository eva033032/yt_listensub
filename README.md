# ListenSub

A lightweight Chrome extension for English listening practice. YouTube keeps playing in its original tab while ListenSub shows a timestamped transcript in a separate, video-free page. Transcript text stays in your browser.

## How to use (Windows)

1. Open `chrome://extensions` in Chrome and turn on **Developer mode**.
2. Select **Load unpacked** and choose this project folder.
3. Open a YouTube video, then click the ListenSub toolbar icon.
4. Paste a timestamped transcript and select **Use transcript**. Example: `[00:01:32] outside. So my morning I will`

Suggested transcript source: [YouTubeTranscript.com](https://youtubetotranscript.com/)

## Features

- Show a pasted transcript in sync with the original YouTube tab's playback time.
- Play or pause YouTube from the subtitle page.
- Adjust caption size, select a YouTube tab, and follow the current caption.

## Limitations

- Transcripts are not fetched or generated automatically; paste one yourself.
- Previous/next sentence navigation is not supported.
- Jumping to a time by entering a timestamp is not supported.
- The YouTube tab must stay open with the video loaded. Some videos may limit controls from a background tab.

# 繁體中文

ListenSub 是用於英語聽力練習的 Chrome 擴充功能。YouTube 保持在原分頁播放，字幕則顯示於獨立頁面，不會播放第二份影片。貼上的逐字稿只儲存在本機瀏覽器。

## 如何操作（Windows）

1. 在 Chrome 開啟 `chrome://extensions`，開啟「開發人員模式」。
2. 點選「載入未封裝項目」，選取本專案資料夾。
3. 開啟 YouTube 影片，再點工具列 ListenSub 圖示。
4. 貼上含時間碼的逐字稿，按 **Use transcript**。例如：`[00:01:32] outside. So my morning I will`

建議逐字稿網站：[YouTubeTranscript.com](https://youtubetotranscript.com/)

## 功能

- 顯示貼上的時間碼字幕，並跟隨 YouTube 播放時間。
- 在字幕頁播放或暫停 YouTube。
- 調整字幕大小、選擇 YouTube 分頁、自動跟隨字幕。

## 尚未支援與限制

- 不會自動取得或產生逐字稿，需自行貼上。
- 上一句／下一句跳轉尚未支援。
- 輸入時間跳轉尚未支援。
- YouTube 分頁需保持開啟並載入影片；部分影片可能限制背景分頁控制。
